# Встраиваемый дизассемблер для "Радио-86РК"

Простой и компактный дизассемблер второй версии для встраивания в ПЗУ **МОНИТОРа** компьютера "**Радио-86РК**" c поддержкой инструкций микропроцессора `8085`, код дизассемблера занимает всего 626 байт.

Дизассемблер рассчитан на стандартный (журнальный) **МОНИТОР** компьютера "**Радио-86РК**" и использует его внутренний буфер и внутренние функции для своих нужд.

## Нестандартные вызовы

Дизассемблер использует следующие вызовы внутренних функций **МОНИТОРа**:

* **OUT_WORD** -- функция вывода слова на экран;
* **CMP_HL_DE** -- функция сравнения регистровых пар **HL** и **DE**;
* **CHECK_CTRL_C** -- функция проверки нажатия комбинации клавиш "**УС+С**".

И использует внутренний буфер **inp_buffer** для хранения:

* **DISASSM_MNEMO** -- код мнемоники, два байта;
* **DISASSM_BUFFER** -- буфер дизассемблированной команды, не менее 24 байта.

Для нестрандартного **МОНИТОРа** необходимо скорректировать значения адресов внутренних функций и буфера.

## Конфигурирование

Дизассемблер имеет два режима:

* дизассемблирование инструкций микропроцессора 8080;
* дизассемблирование инструкций микропроцессора 8085.

Выбор режима осуществляется установкой константы **DISASSM_SUPPORT_8085** в значение **0** или **1** в исходном коде.

Установка константы **DISASSM_SUPPORT_8085** в значение **0** отключает поддержку инструкций микропроцессора 8085, недокументированные коды микропроцессора 8080 в листинге будут отображаться прочерком.

```
DISASSM_SUPPORT_8085	EQU	0
```

Установка константы **DISASSM_SUPPORT_8085** в значение **1** включает дизассемблирование дополнительных 12 команд микропроцессора 8085.

```
DISASSM_SUPPORT_8085	EQU	1
```

## Использование

Дизассемблер поставляется в виде подключаемого файла, для использования в исходном коде необходимо прописать директиву:

```
.include disassm.v2.626.inc.asm
```

## Демо

Демонстрация использования дизассемблера представлена в файле `disassm.launcher.asm` как самостоятельной программы, откомпилированная версия находится в файле `disassm.rk`, запуск дизассемблера производится директивой `<G,7000>`.
