# Встраиваемый дизассемблер для "Радио-86РК"

Простой и компактный дизассемблер второй версии для встраивания в ПЗУ `МОНИТОРа` компьютера "**Радио-86РК**", код дизассемблера занимает всего 625 байт.

Дизассемблер поддерживает инструкции микропроцессора `8085`, подключение инструкций `8085` осуществляется через файл конфигурации.

Для микропроцессора `8080` пустые коды будут дизассемблироваться как недокументированные команды.

Дизассемблер рассчитан на стандартный (журнальный) `МОНИТОР` компьютера "**Радио-86РК**" и использует его внутренний буфер и внутренние функции для своих нужд. Для использования дизассемблера с нестандартным `МОНИТОРом` потребуется изменить адреса вызовов внутренних функций.

Дизассемблер использует следующие вызовы внутренних функций:

* **OUT_WORD** -- функция вывода слова на экран;
* **CMP_HL_DE** -- функция сравнения регистровых пар **HL** и **DE**;
* **CHECK_CTRL_C** -- функция проверки нажатия комбинации клавиш "**УС+С**".

И использует внутренний буфер **inp_buffer** для хранения:
* **DISASSM_MNEMO** -- кода мнемоники, два байта;
* **DISASSM_BUFFER** -- буфер дизассемблированной команды, не менее 16 байт.
